# Task 2: React Signup Application

## Aim
To develop a user signup application using React, Express.js, and MongoDB.

## Technologies Used
- React
- Node.js
- Express.js
- MongoDB
- Mongoose
- bcryptjs

## Features
- User registration with name, email, and password
- Input validation
- Duplicate email checking
- Password hashing using bcrypt
- Store user details in MongoDB

## How to Run
1. Start MongoDB locally.
2. In the `signup-backend` folder, run `npm install` and `npm start`.
3. In the `signup-frontend` folder, run `npm install` and `npm run dev`.
4. Open the frontend URL displayed in the terminal.
